ECOSYSTEM DESTINATION

Creation here.
Exchange elsewhere.

SilverForge creates tokens; it does not list, trade, swap, or provide markets. SilvEx is a separate planned exchange destination and currently has no verified supported market to link to.

Centralized exchange services and decentralized exchange protocols are distinct systems with separate custody and security models.

SECURITY AND HOSTING

Browser-side by design.
Honest about the edges.

Wallets keep the keys

SilverForge requests public account access and transaction signatures from compatible wallets. It never asks for or stores private keys or seed phrases.

Static site, no secret backend

GitHub Pages serves static files only. Public RPC access, wallet extensions and user-selected public metadata storage are external dependencies. Do not put API credentials into the site or browser.

Review and test first

Use testnets while learning. Contract deployments are irreversible and require network fees; verify bytecode, supply and target network before signing.
